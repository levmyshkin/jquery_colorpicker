Color Picker without jQuery

This page doesn't load jQuery.

Input field

var picker = new ColorPicker('#field', {
  onBeforeShow: function () { picker.setColor(this.value); },
  onSubmit: function (hsb, hex, rgb, el) { el.value = hex; picker.hide(); }
});

Swatch with live preview

0000ff

new ColorPicker('#swatch', {
  color: '#0000ff',
  onChange: function (hsb, hex) {
    document.getElementById('swatch').style.backgroundColor = '#' + hex;
    document.getElementById('hex').textContent = hex;
  }
});
